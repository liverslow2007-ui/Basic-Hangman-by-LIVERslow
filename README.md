# Basic-Hangman-by-LIVERslow
A classic terminal-based Hangman game built using Python. The game randomly selects a secret word from a predefined list and challenges the player to guess it letter by letter before running out of lives.

Features
Random Word Selection: Randomly selects a word from a list of 20 distinct dictionary words for each game session.

Dynamic Word Display: Shows underscores (_) representing hidden letters, updating in real-time as correct guesses are made.

Lives System: Gives the player 10 lives to guess the word, reducing lives only on incorrect guesses.

Case-Insensitive Input: Automatically converts user input to lowercase so players can enter capital or lowercase letters seamlessly.
